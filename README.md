# 票证私盒 SafeDoc Local

**100% 纯浏览器本机内存运行的电子发票 A4 省纸拼版 · 身份证/营业执照防盗用水印 · 合同不可逆像素脱敏工作台**

- **立即免费在线使用（无需注册登录）**：**https://logizhang.github.io/safedoc-local/**
- **隐私安全可验证**：打开浏览器开发者工具（F12 → Network）或直接**拔掉网线/断开 Wi-Fi**，所有发票、身份证、合同均 100% 在本机内存中完成解析与导出，**0 字节上传任何服务器**。

---

## 为什么做这个工具？

日常财务报销贴票、HR 入职背调、租房备案、对外发送合同时，国内用户普遍面临两个痛点：
1. **免费在线网页工具隐私裸奔**：搜索出来的在线拼发票、加水印网站，往往强制将你的身份证正反面、营业执照、发票明细上传到不明远端服务器处理。
2. **传统办公套件会员昂贵**：为了一个月用一次的“多张电子发票合并一页打印”或“PDF 脱敏”，动辄需要开通 ¥98–¥198/年的连续包年会员。

**《票证私盒 SafeDoc Local》** 采用纯前端离线计算引擎（内置本地 PDF 光栅化与二进制 PDF 1.4 / ZIP 封装器），让你在浏览器里断网也能安全完成全套票证处理。

## 核心功能一览

### 1. 电子发票 A4 省纸拼版打印（财务报销刚需）
- 支持拖入 **PDF 电子发票** 或 **JPG / PNG 发票截图**，矢量级高清渲染不发虚。
- 支持 **一页 A4 排 2 张（上下对开）** 或 **一页 A4 排 4 张（四宫格省纸模式）**。
- **财务规范细节**：
  - 内置 **「预留左侧 15mm 财务装订线」** 开关，打孔装订不压发票代码与金额；
  - 内置裁剪辅助虚线与序号标记；
  - 支持自动附加 **「费用报销电子发票打印附件汇总签字单」**（Pro）。

### 2. 身份证 / 营业执照 防盗用水印与 A4 正反面合版
- 预置入职背调、租房备案、企业开户年审、实名办卡等高频防盗用警示词条，自动附加当日日期戳。
- 支持 **身份证正反面双图一键居中合成标准 A4 打印页**（Pro），连打印机即可递交政务或人事窗口。
- 支持多张证件一键批量加水印并打包导出 ZIP（Pro），可选防 AI 擦除微噪点干扰纹。

### 3. 合同 / 报价单 不可逆像素级涂黑脱敏
- 普通编辑器在 PDF 上画黑色矩形框，底层文字往往仍可被鼠标复制提取。
- 本工具支持框选身份证号、银行卡号或商业底价后，直接将页面重绘为单层位图导出 PNG / PDF，**物理销毁选区底层像素与文本层，彻底不可逆还原**。

## 本地离线部署方式

如果你想在内网办公电脑或完全无网环境下运行：

```bash
git clone https://github.com/LogiZhang/safedoc-local.git
```

进入目录后直接用现代浏览器（Edge / Chrome / Safari）双击打开 `index.html`，或运行 `python3 -m http.server 8080` 访问本地端口即可使用。
